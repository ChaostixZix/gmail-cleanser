# gmail-cleanser

## Overview
Next.js Gmail management app for searching, reviewing, and bulk-deleting inbox messages through Google OAuth.

## Problem
Cleaning large Gmail inboxes is tedious when search, review, and delete workflows are scattered across the default interface.

## Solution
This repository provides a focused inbox cleanup application with Gmail API integration, bulk actions, and advanced search support.

## Demo
No public demo is documented.

## Setup
```bash
cp .env.example .env.local
bun install
bun run dev
```
